🍅 Pomodoro Timer

Stay focused and get more done with the Pomodoro technique

25:00

How it works:

  1. Decide on the task to be done.
  2. Set the Pomodoro timer (typically 25 minutes).
  3. Work on the task until the timer rings.
  4. Take a short break (typically 5 minutes).
  5. After four Pomodoros, take a long break (typically 15 minutes).
